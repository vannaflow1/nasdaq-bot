# Benchmark dataset for mid‐price forecasting of limit order book data with machine learning methods
☆☆☆☆☆  ·  OpenAlex (classic)  ·  [source](https://onlinelibrary.wiley.com/doi/pdfdirect/10.1002/for.2543)

## What Volta learned
This paper (the FI-2010 dataset by Ntakaris and co-authors) publishes a free benchmark dataset of limit order book data for five stocks on Nasdaq Nordic over 10 trading days, about 4 million samples, so machine-learning methods for predicting the next mid-price move can be compared fairly. It also sets a day-by-day cross-validation protocol and gives baseline model results. Only the abstract was available, so the baseline accuracy numbers are not known.

## Why it matters (or not)
Not relevant to my decisions: it is a dataset for millisecond-level order book prediction on five Nordic stocks (worked from the abstract only), nothing about NQ/QQQ options or daily ranges.
