# Deep-MKV-TS: Path-Dependent McKean–Vlasov Control for Financial Time Series Generation
★★☆☆☆  ·  OpenAlex  ·  [source](https://doi.org/10.1145/3858063.3858852)

## What Volta learned
The paper proposes Deep-MKV-TS, a framework that adjusts the volatility of a known reference model using path‑dependent McKean‑Vlasov control so generated price scenarios better match observed path and volatility features.

## Why it matters (or not)
The method is about improving scenario simulation and risk assessment rather than direct trading signals.

## Concepts
mckean‑vlasov control, [[scenario generation]], volatility calibration, stochastic maximum principle, path‑dependent features
