# Improving Generalization in Reinforcement Learning–Based Trading by Using a Generative Adversarial Market Model

## What Volta learned
The paper discusses using a generative adversarial model (LOB-GAN) to simulate a financial market for training reinforcement learning (RL) agents in portfolio management. This approach aims to improve the agent's generalization capabilities by accounting for market impact and causal relationships. The framework shows a 4% improvement in out-of-sample portfolio performance.
