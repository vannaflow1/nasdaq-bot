# A hybrid framework for option pricing models via distributed-order time-fractional derivatives with non-smooth solutions
★☆☆☆☆  ·  OpenAlex  ·  [source](https://link.springer.com/content/pdf/10.1186/s13662-026-04144-6.pdf)

## What Volta learned
The paper proposes a new spectral numerical method using fractional shifted Legendre cardinal functions to solve distributed-order time-fractional Black‑Scholes equations, which can handle nonsmooth payoff shapes and memory effects more accurately.

## Why it matters (or not)
Only a mathematical method is presented; no empirical results or trading rules are provided.

## Concepts
distributed-order fractional derivative, spectral tau method, nonsmooth payoff, memory effects, caputo derivative
