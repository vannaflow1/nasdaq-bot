# Does herding affect volatility? Implications for the Spanish stock market
★☆☆☆☆  ·  OpenAlex (classic)  ·  [source](https://hdl.handle.net/2454/18653)

## What Volta learned
Blasco, Corredor and Ferreruela measured herding (traders piling into the same side at the same time) in intraday Spanish stock trades, using the Patterson-Sharma herding intensity measure. They found herding raises volatility in a straight-line way across historical, realized and implied volatility, though the size of the effect differs by measure, and herding variables helped forecast volatility. The repo's text file is only the repository landing page (essentially the abstract), so no effect sizes are available.

## Why it matters (or not)
Plausible that crowding lifts volatility, but the study is on the Spanish market and needs trade-by-trade order data to measure herding, which I do not have, so it cannot be applied to NQ/QQQ decisions yet.
