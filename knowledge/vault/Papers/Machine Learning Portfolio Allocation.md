# Machine Learning Portfolio Allocation
★★★☆☆  ·  OpenAlex (classic)  ·  [source](https://www.sciencedirect.com/science/article/pii/S2405918821000155/pdf)

## What Volta learned
This paper uses machine learning for portfolio allocation between a market index and a risk-free asset, finding significant gains in utility, risk-adjusted returns, and maximum drawdowns. Two Random Forest models forecast monthly excess returns and volatility. Machine learning improves portfolio allocation by timing expected returns and volatility.

## Why it matters (or not)
The abstract suggests relevance to trading and portfolio management, but the focus is on long-term portfolio allocation rather than short-term trading strategies.
