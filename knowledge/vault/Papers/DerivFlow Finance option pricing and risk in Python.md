# DerivFlow Finance: option pricing and risk in Python
★★☆☆☆  ·  OpenAlex  ·  [source](https://doi.org/10.5281/zenodo.23932347)

## What Volta learned
The paper describes a Python library called DerivFlow Finance that implements pricing for many option types, Greeks, Monte‑Carlo variance reduction, the Heston stochastic‑volatility model, volatility surfaces, and portfolio VaR, validated against other libraries.

## Why it matters (or not)
The content is about a software tool; it may help build models but provides no empirical results for trading.
