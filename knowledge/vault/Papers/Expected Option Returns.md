# Expected Option Returns
★★★★☆  ·  OpenAlex (classic)  ·  [source](https://onlinelibrary.wiley.com/doi/pdfdirect/10.1111/0022-1082.00352)

## What Volta learned
The paper finds that expected call option returns are higher than the underlying security and increase with strike price, while expected put option returns are lower than the risk-free rate and also increase with strike price. S&P index options show these characteristics. Zero-beta straddle positions tend to produce average losses.

## Why it matters (or not)
The abstract provides insights into option returns and their relationship with strike prices and betas, which can be useful for traders, especially those trading S&P index options.
