# Daily options tables (2008 - Dec 2025)

One row per trading day per symbol: dealer gamma (GEX) and its 1-year rank, open interest, volume, ATM implied vol
(front and 30-day), term ratio and 25-delta skew. Built by `tools/options_daily.py` from the free daily dataset at
github.com/philippdubach/options-data ("for educational and research purposes"; end-of-day, not intraday).

Status: data only. Nothing has been related to NQ prices or tested. Any test on it is a new family and needs the
owner's OK and an alpha slot (see knowledge/proposals/).
